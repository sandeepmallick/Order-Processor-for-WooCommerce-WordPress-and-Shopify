# Order Processor GUI

A simple desktop GUI application that automates daily order processing for **WordPress** and **Shopify** stores.

## Features

- Import daily order Excel files from WordPress or Shopify.
- Automatically extract the following information:
  - Date
  - Order No.
  - Customer Name
  - Book Name
  - Quantity (QTY)
  - Weight (WT)
  - Shipping Address (Address 1 & 2)
  - City
  - State Code
  - Postcode
  - Country Code
  - Customer Note
- Convert and organize the data into a clean, standardized Excel sheet.
- Saves time by eliminating manual data entry.

## Output

The application generates a processed Excel file containing all required shipping and order details, ready for further processing.

## Purpose

This tool was created to simplify the daily workflow of processing WooCommerce (WordPress) and Shopify orders by converting raw order exports into a structured format.
